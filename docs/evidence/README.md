The screenshots intentionally omit passwords, API keys, database connection
details, instructor email addresses, browser tokens, and unnecessary account
identifiers. UUIDs belonging to synthetic survey records may remain where they
demonstrate relational persistence; they are not credentials or student
identities.

Do not replace these images with mockups. Any future evidence must come from the
real application or hosted Supabase project, use synthetic data, and be reviewed
across the entire frame before it is committed.
